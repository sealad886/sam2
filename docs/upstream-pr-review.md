This is a review and adaptation queue. No upstream contribution is assumed correct because it is open, has an approval, or claims a benchmark. The reviews used actual file patches, current callers and the complete paginated discussion/review histories. Large feature proposals were reviewed sufficiently to determine boundaries and defer them; hardware, browser, translation and performance claims remain unqualified where stated. Generated notebook outputs and binary samples were not executed.

## Fork maintenance recommendations

Keep the upstream Git remote and Meta research/license/citation attribution. Maintain this ledger as the single provenance and deduplication index, and link original PRs in adaptation descriptions and commits. Review upstream changes before importing them; avoid automatic merges or rebases that rewrite a published branch.

Run fork-owned read-only CI on all PR bases so stacked fixes are tested without repeating the MPS baseline diff. Validate installed wheels outside the checkout. Keep minimum/current PyTorch coverage and identify accelerator skips honestly. A trusted manual Apple Silicon qualification can supplement hosted runners; do not expose a personal self-hosted runner to arbitrary public PR code. Container and CUDA claims should remain separate from the native Mac inference claim.
